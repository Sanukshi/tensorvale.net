# TensorVale.net

Premium frontend for **TensorVale** — an AI Model Evaluation & Experimentation Platform.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
